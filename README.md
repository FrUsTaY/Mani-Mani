## 🌟 Обзор
**ManiMani** — это современное приложение для учета личных финансов, ориентированное на конфиденциальность и созданное специально для Android. Оно автоматизирует учет расходов путем интеллектуального парсинга банковских уведомлений и предоставляет глубокую аналитику вашего финансового состояния с помощью ИИ Gemini.

## ✨ Ключевые возможности
*   **🤖 ИИ-ассистент Gemini:** Общайтесь с умным финансовым помощником, чтобы анализировать свои траты, получать советы по бюджету и сводки за месяц.
*   **📲 Автоматический учет (через пуши):** Приложение слушает входящие банковские пуш-уведомления, автоматически категоризирует и сохраняет ваши транзакции.
*   **🧾 Фискальные чеки (54-ФЗ) и ФНС:** Прикрепляйте фото чеков с камеры или галереи, сканируйте QR-коды чеков (Google ML Kit) и загружайте детализацию покупок (список товаров, цены, НДС, продавец) напрямую из ФНС через API «Проверка Чека» с автоматической сверкой сумм.
*   **📊 Зарплатные циклы и бюджет:** Планируйте бюджет с умом — на основе ваших реальных зарплатных циклов (от зарплаты до зарплаты), а не строгих календарных месяцев.
*   **📈 Продвинутая аналитика:** Наглядные графики и диаграммы для распределения доходов и расходов.
*   **💾 Резервное копирование и восстановление:** Экспорт и импорт базы данных вместе со всеми прикрепленными фотографиями чеков в единый ZIP-архив с проверкой целостности данных.
*   **🎨 Современный интерфейс:** Полностью построен на Jetpack Compose с использованием принципов Material Design 3 для плавного, адаптивного и красивого пользовательского опыта.
*   **🔒 Локальное хранение (Privacy-First):** Все ваши конфиденциальные финансовые данные безопасно хранятся прямо на устройстве с использованием Room Database.

## 🛠 Технологический стек
*   **Язык:** [Kotlin](https://kotlinlang.org/) (100%)
*   **UI Тулкит:** [Jetpack Compose](https://developer.android.com/jetpack/compose) + Material 3
*   **Архитектура:** MVVM (Model-View-ViewModel) + принципы Clean Architecture
*   **База данных:** [Room](https://developer.android.com/training/data-storage/room) (SQLite)
*   **Камера & QR-сканирование:** CameraX + [Google ML Kit Barcode Scanning](https://developers.google.com/ml-kit/vision/barcode-scanning)
*   **Сетевой слой:** Retrofit, OkHttp, Moshi
*   **Асинхронность:** Kotlin Coroutines & Flow
*   **ИИ Интеграция:** Google Gemini API SDK

## 🛠 Для разработчиков: локальная сборка и запуск

Исходный код открыт для ознакомления с архитектурой, изучения реализации отдельных компонентов (Jetpack Compose, Gemini API, ML Kit, Room) и локального тестирования.

### Требования к окружению
* Android Studio (Ladybug / Koala / Meerkat или новее)
* JDK 17 или 21 (по умолчанию встроен в Android Studio как JBR)
* Android SDK 34+

### Шаги для сборки (Debug APK):

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/FrUsTaY/Mani-Mani.git
   cd Mani-Mani
   ```

2. **Открытие в Android Studio:**
   * Запустите Android Studio.
   * Нажмите **File -> Open...** и выберите корневую папку проекта (`Mani-Mani`).
   * Дождитесь завершения автоматической синхронизации Gradle (Gradle Sync).

3. **Сборка APK:**
   * **Через интерфейс Android Studio:**
     В верхнем меню выберите **Build** ➔ **Build Bundle(s) / APK(s)** ➔ **Build APK(s)**.
     После завершения сборки появится уведомление со ссылкой `locate` на готовый файл `.apk`.
   * **Через терминал:**
     * **Windows:**
       ```cmd
       gradlew.bat assembleDebug
       ```
     * **Linux / macOS:**
       ```bash
       ./gradlew assembleDebug
       ```
     Готовый APK будет находиться по пути:
     `app/build/outputs/apk/debug/app-debug.apk`

4. **Настройка API-ключей (опционально):**
   * **Gemini API:** Для работы ИИ-ассистента укажите ваш Gemini API ключ в настройках приложения (экран Gemini Assistant) или скопируйте `.env.example` в `.env` и пропишите ключ там.
   * **Проверка Чека (ФНС):** Для автоматической загрузки позиций чека укажите личный токен с сайта proverkacheka.com в настройках приложения (вкладка «Счета» ➔ «Настройки чеков»).
   * Базовые функции учета расходов, счетов, фотосъемки чеков и парсинга уведомлений работают автономно и без внешних ключей.

## 📂 Структура проекта
*   `app/src/main/java/com/example/ui/` - Экраны и компоненты интерфейса (Jetpack Compose)
*   `app/src/main/java/com/example/data/` - База данных Room, DAO, сущности и репозитории
*   `app/src/main/java/com/example/service/` - Слушатель уведомлений, интеграция с Gemini, сканер чеков и сетевой API ФНС
*   `scripts/` - Вспомогательные скрипты и исторические патчи
